# simpletel-skill

[simpletel](https://simpletel.dev) agent skills, packaged for every agent:

- `simpletel-onboard` — onboard an application with upstream OpenTelemetry.
- `simpletel-embed` — embed simpletel inside an app (simpletel-embed
  sidecar via Go/Django/Rust adapters, in-app trace viewer).
- `simpletel-troubleshoot` — find and diagnose failing or slow requests
  from an app's traces (list → detail → events + correlated logs).

The skill bodies are byte-identical across every install route below.

## Install

### Claude Code — plugin marketplace

```
/plugin marketplace add willnewby/simpletel-skill
/plugin install simpletel@simpletel
```

### Pi — skill package

```
pi install git:github.com/willnewby/simpletel-skill
```

### Any agent — via the simpletel CLI

```
simpletel skill install --agent claude   # or --agent codex, or --agent pi
```

## Generated repo

Do not hand-edit `skills/*/SKILL.md` or the manifests. This repo is
generated by `simpletel skill package`; regenerate it from the simpletel
binary so the install routes never drift.
