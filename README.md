# simpletel-skill

[Pi](https://pi.dev) skill package for [simpletel](https://simpletel.dev):

- `simpletel-onboard` — onboard an application with upstream OpenTelemetry.
- `simpletel-embed` — embed simpletel inside an app (simpletel-embed
  sidecar via Go/Django/Rust adapters, in-app trace viewer).

Install it with Pi's package manager:

```
pi install git:github.com/willnewby/simpletel-skill
```

The skill bodies are byte-identical to `simpletel skill install --agent pi`.
This repo is generated by `simpletel skill package` — do not hand-edit
`skills/*/SKILL.md`; regenerate it from the simpletel binary so the two
install routes never drift.
