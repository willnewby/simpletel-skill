# simpletel-skill

A [Pi](https://pi.dev) skill package that onboards an application to
[simpletel](https://github.com/willnewby/simpletel) using upstream
OpenTelemetry. Install it with Pi's package manager:

```
pi install git:github.com/willnewby/simpletel-skill
```

The onboarding body is byte-identical to `simpletel skill install --agent pi`.
This repo is generated by `simpletel skill package` — do not hand-edit
`skills/simpletel-onboard/SKILL.md`; regenerate it from the simpletel
binary so the two install routes never drift.
